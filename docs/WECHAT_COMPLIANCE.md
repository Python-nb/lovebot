核对日期：2026-10-26。本文是项目执行规范和验收清单，不是法律意见、平台审核通过证明或面向用户的正式隐私政策。

## 官方依据

已读取微信官方原页；搜索服务无法打开时，使用公开文档 HTML 核对正文，未登录或改变微信后台。

- [小程序隐私协议开发指南](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)：先在后台如实声明实际处理的信息，用户同意后调用对应接口；未实现自定义弹窗时可使用微信默认弹窗。拒绝后不可绕过平台检查。
- [用户隐私保护指引填写说明](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/index)：现网和提审版本有不同入口，更新一处不能视为另一版本也已生效。
- [小程序用户隐私保护指引内容介绍](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/miniprogram-intro)：“访问你的蓝牙”对应 openBluetoothAdapter、蓝牙权限等接口；必须真实说明用途。
- [wx.requirePrivacyAuthorize](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/privacy/wx.requirePrivacyAuthorize.html)：使用平台授权回调，不用本地布尔值代替同意。
- [wx.openPrivacyContract](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/privacy/wx.openPrivacyContract.html)：打开微信正式隐私指引，接口不支持 Promise 风格，代码用回调适配。
- [wx.openBluetoothAdapter](https://developers.weixin.qq.com/miniprogram/dev/api/device/bluetooth/wx.openBluetoothAdapter.html)：需要 scope.bluetooth；隐私授权与手机系统权限不是同一层。
- [手机号能力](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/getPhoneNumber.html)：非个人、已认证主体等资格以当前平台为准，可能计费；需用户主动点击原生授权按钮，服务端核验专用 code，不能把 wx.login code 当手机号凭证。
- [微信登录服务端核验](https://developers.weixin.qq.com/miniprogram/dev/OpenApiDoc/user-login/code2Session.html)：AppSecret 只放服务端，临时 code 必须换取并核验真实身份后才建立业务会话。

## 实际代码与声明对应

| 内容 | 用途与范围 | 保存方式 |
| --- | --- | --- |
| 蓝牙设备名、设备标识、RSSI、连接状态 | 用户主动搜索/连接发球机、核验、展示信号 | 当前运行内存，不保存设备历史；信号每 10 秒读取，隐藏/断连/卸载清理 |
| 发球数、进球数、时长、模式、结束时间、核对标记 | 训练显示、核对与统计 | 新游客训练只在当前运行内存中，关闭/切换账号/再次训练后不保留；账号草稿和已核对成绩存微信本机缓存，主动同步的记录才进入 MySQL，保留到主动删除/注销；草稿不上传。旧游客缓存原样保留且不自动展示/上传 |
| 手动输入的昵称 | 我的页面展示，不读取微信昵称或头像 | 游客本机保存；登录后更正账号昵称会提交服务端 |
| 微信 code、OpenID、手机号授权 code 与微信返回的号码 | 用户主动登录、绑定或重置时核验身份和号码 | code/原始身份及号码只临时用于请求；MySQL 仅存带密钥身份/号码摘要和手机号掩码 |
| 独立账号名与密码 | 用户主动注册/登录；用户名不代表真实身份，不使用短信 | MySQL 存规范化用户名与带密钥索引、随机盐密码摘要；客户端不缓存密码 |
| 密码、业务会话 | 手机号密码校验及鉴权 | 服务端存随机盐 scrypt 密码摘要与会话摘要；客户端仅缓存不透明业务会话，最长 7 天；密码不持久化 |
| 系统外观、用户外观偏好 | 浅深色适配 | 系统外观即时读取，偏好本机保存 |
| 开发版主动开启的 BLE 诊断 | 区分订阅、启动门槛、写入与通知/解析失败 | 现有云环境中的独立诊断服务短期应用日志；一次性编号、白名单事件/时间/错误码与最多 3 条脱敏形状样本，无账号、完整设备标识或训练记录；当前配置关闭，保存期限待平台设置 |

账号与数据服务代码已实现，但客户端配置开关关闭，未宣称真实登录核验完成。游客连接/训练不请求账号服务或上传；主动打开头像登录面板会查询账号服务能力。账号明确登录/同步/导入/删除才发起对应请求，无静默合并。没有位置、相机、麦克风、相册、通讯录、广告/统计 SDK 或第三方插件；不能宣称整个微信环境不联网。云托管 MySQL 备份期限和删除恢复策略须由运营方确认并填写正式指引，不能臆造天数。

## 代码已实现

- 头像是主动登录入口；游客不强制登录或提供手机号即可使用 BLE。新游客训练只在内存展示，本次核对不调用账号数据库或写本机训练缓存。切后台时已核对结果清空，进行中/待核对状态仍提示现场停机与核对；离开造成系统回收则不可恢复。旧版游客缓存留存且不自动混入新单次统计。
- 用户主动搜索或连接时调用微信隐私授权，未同意则不访问蓝牙。没有启动即强迫同意、默认勾选、假同意或因拒绝强制退出。
- “我的 → 用户隐私保护指引”调用微信正式入口；打开失败显示可消失的真实错误，不伪造政策已配置。
- “数据使用与管理”说明处理类型、目的、存储/期限、共享、权利、未成年人及官方联系渠道；它只是业务补充说明。
- 已保存记录主动确认删除。游客删除仅处理旧版游客本机缓存，单次内存结果不受此操作影响；当前账号本机缓存删除不影响其他身份、昵称或主题。账号内另有云端记录删除及注销，须二次确认，不发送设备控制命令。其他设备旧缓存不被远程擦除。进行中或待核对训练先处理完毕再操作账号/数据。
- 登录/注册说明默认不勾选，拒绝不强迫退出；微信登录不捆绑手机号。独立用户名密码注册无短信，不自动合并微信账号；忘记密码暂不开放仅凭用户名重置。可选的微信手机号注册需原生授权双重核验；微信重置仍需近期微信登录和原生授权。关闭/隐藏/卸载清空凭据表单与授权 code；会话保持账号隔离。代码和离线测试不证明真实部署。
- 隐私失败、关闭授权/扫描、迟到 RSSI 等路径有离线回归。没有实际发起用户授权或修改系统权限的验收证据。

## 管理员仍须完成，不得假定已生效

- [ ] 微信公众平台中核对真实运营主体、隐私负责人/有效联系方式及处理方式；客户端不填写猜测的公司或邮箱。
- [ ] 在“账号设置 → 服务内容声明 → 用户隐私保护指引”核对蓝牙、账号身份、手机号及密码摘要、会话、训练同步、昵称等真实用途和保存位置/期限；以后台字段为准，不为了过审申报未使用权限。
- [ ] 核对手机号主体资格、配额/费用、备份保留期限和恢复后的删除处理、云服务委托处理范围及权利请求流程；关闭账号/备份不等于自动擦除其他设备缓存。完成真实联调再打开账号服务开关。
- [ ] 独立账号启用前完善正式指引中账号名、密码摘要、会话及联系渠道；核验网关防暴力尝试与人工身份核验流程。002 数据库迁移经备份/维护窗口审阅后单次执行，不在普通部署中自动 ALTER。
- [ ] 开发版诊断启用前，按用户最新选择在 `prod` 环境新建独立诊断服务（不复用账号服务或其密钥），限制入口、设置短期应用日志保留/删除、核对平台正式隐私指引的诊断用途与处理范围；先真机验证关闭、拒绝、超时、失败均不影响 BLE 控制。不能把默认关闭的本地代码当成已上线诊断。
- [ ] 区分现网指引与提审版本指引。开发版上传不代表指引已完善或审核通过。
- [ ] 真机检查正式指引可打开；首次允许、拒绝、重新授权及撤回后蓝牙均符合预期。拒绝蓝牙权限不妨碍查看账号已有本机记录或本次已核对结果。
- [ ] 真机分别以游客和账号验收：游客拒绝登录/手机号仍可连接 BLE，前后台中断后安全提示可见，关闭/切换身份/新训练后本次结果不保留；账号记录仅手动同步，旧游客记录需明确导入。旧游客草稿不会自动恢复，必要时安排数据迁移或支持说明。
- [ ] 如新增登录、云同步、多人榜、SDK 或新权限，先更新代码/数据流和隐私声明，再按平台要求重新获取相应同意。
- [ ] 厂商协议、真机安全和双端 BLE 验证完成后，再按授权执行体验/提审/正式发布，不由开发版上传推导“生产可用”。
