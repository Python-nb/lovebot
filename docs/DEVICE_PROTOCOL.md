# 设备协议与现场安全

依据用户提供的擎点体育发球机 T1.2 协议。服务 `4fafc201-1fb5-459e-8fcc-c5c9c331914b`；写入 RX `beb5483e-36e1-4688-b7f5-ea07361b26a8`；通知 TX `6e400003-b5a3-f393-e0a9-e50e24dcca9e`。

| 操作 | ASCII，不加换行 |
| --- | --- |
| 启动 / 停止 | `Turn-on` / `Turn-off` |
| 定时 10 分钟 | `SET1#600#` 后 `Turn-on` |
| 定数 100 球 | `SET2#100#` 后 `Turn-on` |
| 自由训练 | 只发 `Turn-on`；回传模式非 0 则拒绝，要求机器端切回自由模式 |

接收 `101,发球数,进球数,工作时长,模式,目标,9,`；按定界拆包粘包，七个非负整数字段、头尾固定、模式 0/1/2，进球不大于发球。不把 notify 边界当帧，不接受模拟来源成绩。

## 厂商与真机待确认

- 正文写 `STE1`，示例写 `SET1`；采用示例，不在失败后换拼写自动重试。
- 工作时长暂按秒；协议未明确单位，确认前不认证成绩或计费。
- 无模式切换 ACK、停止 ACK、运行标志或自由模式重置指令，不能编造。
- 启动是否清零/累计、最终帧及计数语义未知；展示原始回传，保存前现场核对。
- 定时 1–180 分钟、定数 1–9999 是客户端边界，不代表硬件已验证。

## 安全策略

真实连接和新鲜回传才能启动。通知停滞超过 3.5 秒、断连或切后台进入中断，必要时仅尝试一次停止；不自动重连、补发启动或重试写入。调用成功不证明实体停止，超时也可能已执行，始终准备机器实体停止开关。

保存、放弃草稿、切换账号不能恢复发球。真实训练须确认停机与最终数据；本机存储失败不得显示保存成功。联调须在安全区域完成双端权限、三模式、目标停止、切后台和异常测试。
